# FullStack Cars Company ASP.NET

A full-stack web application for managing a car company platform using ASP.NET, C#, SQL Server, JavaScript, and CSS.

## Project Overview

This project was developed as a full-stack web application that simulates a car company platform. It focuses on both frontend and backend development, including page performance, session handling, local storage usage, and database integration.

The project demonstrates practical experience in building a structured web application with ASP.NET and C#, while applying software engineering principles to guide architecture and technology choices.

## Features

- car-related web platform structure
- session management
- local storage usage
- SQL Server database integration
- frontend styling and page design
- backend logic implemented with C# and ASP.NET

## Tech Stack

- ASP.NET
- C#
- SQL Server
- JavaScript
- CSS
- HTML

## Project Structure

- solution file for the ASP.NET project
